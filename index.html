Support

Questions fréquentes

Y a-t-il une version Mac / Linux ?

Pas pour la beta. La v1.0 cible Windows pour aller vite. Linux et macOS sont prévus en v1.1 — la base Godot le permet sans réécriture.

Windows m'empêche d'ouvrir le jeu (« Windows a protégé votre ordinateur »)

C'est normal : le jeu n'est pas encore signé numériquement (un certificat coûte cher). Le jeu est sain. Clique sur « Informations complémentaires » puis « Exécuter quand même ». Tu peux vérifier l'intégrité du fichier avec le SHA-256.

Le jeu est-il gratuit ?

Oui, totalement. Aucun achat in-app, aucune publicité. Le client est libre, le serveur peut être auto-hébergé sans frais.

Puis-je jouer hors ligne ?

Oui : Solo vs IA, multi local hot-seat et tournoi fonctionnent 100% offline. Seul le multijoueur en ligne nécessite un serveur.

Mes parties multi sont-elles privées ?

Oui si tu utilises l'option --password= sur ton serveur dédié. Les hôtes "amis" peuvent aussi définir un mot de passe via l'interface.

Combien de joueurs maximum ?

Jusqu'à 10 joueurs simultanés, en local comme en ligne.

Comment signaler un bug ou demander une fonctionnalité ?

Écris à kmerek7@protonmail.com avec une capture d'écran et la version (visible en bas du menu principal).

Puis-je jouer en LAN sans Internet ?

Oui. Sur le même réseau local, héberge depuis le menu "Multijoueur en ligne" et donne ton IP locale aux autres. Pas besoin de VPS.
