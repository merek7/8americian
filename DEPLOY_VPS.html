Auto-héberger un serveur

Guide v1.01.beta — durci : rate-limit RPC, mot de passe, utilisateur dédié non-root.

Pré-requis

  • Linux x86_64 (Ubuntu/Debian recommandé)
  • 1 CPU, 512 Mo RAM minimum
  • Port UDP 9080 ouvert (firewall + provider)
  • Accès SSH (sudo)

1️⃣ Créer un utilisateur dédié (non-root)

sudo useradd -r -m -s /bin/bash jeucartes
sudo mkdir -p /opt/jeu-cartes
sudo chown -R jeucartes:jeucartes /opt/jeu-cartes

2️⃣ Installer Godot

sudo apt update && sudo apt install -y wget unzip
cd /opt
sudo wget https://github.com/godotengine/godot/releases/download/4.6.2-stable/Godot_v4.6.2-stable_linux.x86_64.zip
sudo unzip Godot_v4.6.2-stable_linux.x86_64.zip
sudo mv Godot_v4.6.2-stable_linux.x86_64 godot
sudo chmod +x godot
sudo ln -sf /opt/godot /usr/local/bin/godot
godot --version

3️⃣ Copier le projet

Télécharge l'archive serveur depuis le site, puis :

scp server-package.tar.gz user@TON_IP_VPS:/tmp/
ssh user@TON_IP_VPS
sudo tar -xzf /tmp/server-package.tar.gz -C /opt/jeu-cartes --strip-components=1
sudo chown -R jeucartes:jeucartes /opt/jeu-cartes

4️⃣ Premier import (une fois)

sudo -u jeucartes env HOME=/opt/jeu-cartes godot --headless --path /opt/jeu-cartes --import

5️⃣ Service systemd (auto-restart)

Crée /etc/systemd/system/jeu-cartes.service :

[Unit]
Description=8 American — serveur dédié
After=network.target

[Service]
Type=simple
User=jeucartes
Group=jeucartes
WorkingDirectory=/opt/jeu-cartes
Environment=HOME=/opt/jeu-cartes
ExecStart=/usr/local/bin/godot --headless --path /opt/jeu-cartes -- \
  --server --port=9080 --start-on=2 --score=50 --password=CHANGE_MOI
Restart=always
RestartSec=5
NoNewPrivileges=true
ProtectSystem=strict
PrivateTmp=true
ReadWritePaths=/opt/jeu-cartes

[Install]
WantedBy=multi-user.target
🔐 Remplace CHANGE_MOI par un mot de passe fort (12+ caractères). Génération rapide :
openssl rand -base64 16 
sudo systemctl daemon-reload
sudo systemctl enable --now jeu-cartes
sudo journalctl -u jeu-cartes -f

6️⃣ Ouvrir le port (firewall)

sudo ufw allow 9080/udp
sudo ufw reload

Côté provider (panel web Hetzner / OVH / DigitalOcean), ouvre aussi UDP 9080.

7️⃣ Connexion depuis le client

  1. Lance le client Windows
  2. "Multijoueur en ligne" → onglet "Rejoindre"
  3. IP : ton IP VPS publique
  4. Port : 9080
  5. Mot de passe : celui défini dans --password=
  6. Rejoindre

Flags CLI disponibles

FlagDéfautDescription
--server—Active le mode dédié
--port=X9080Port UDP d'écoute
--start-on=N2Démarre auto à N joueurs
--score=X50Score cible (50 ou 100)
--password=XXX(aucun)Mot de passe requis

Mise à jour

scp new-server-package.tar.gz user@VPS:/tmp/
ssh user@VPS
sudo systemctl stop jeu-cartes
sudo tar -xzf /tmp/new-server-package.tar.gz -C /opt/jeu-cartes --strip-components=1
sudo chown -R jeucartes:jeucartes /opt/jeu-cartes
sudo -u jeucartes env HOME=/opt/jeu-cartes godot --headless --path /opt/jeu-cartes --import
sudo systemctl start jeu-cartes

Sécurité — récap v1.01.beta

  • Utilisateur non-root via systemd User=jeucartes
  • Hardening systemd (NoNewPrivileges, ProtectSystem, PrivateTmp)
  • Mot de passe serveur, kick si invalide
  • Rate-limit 30 RPC/sec/peer, kick auto si dépassé
  • Pseudo plafonné à 32 caractères, caractères de contrôle filtrés
  • Validation : seul un joueur de la partie peut continuer la manche

Limites : trafic ENet non chiffré (sniffer Wi-Fi voit les noms/scores). Pour usage public sur Internet exposé, ajouter DTLS dans une version future.
